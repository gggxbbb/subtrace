# 记录驱动的到期日与双跟踪模式

订阅到期日不由"起始日 + 周期"永久推算（Wallos 的做法），而是等于最后一笔付费记录的服务止期；仅在没有付费记录时才用锚定日期 + 计费周期推算兜底。订阅分两种跟踪模式：周期模式（存锚定日期、周期、标准价，付费记录会改写锚点）和手动模式（不维护周期，每次付费直接记录金额与新到期日）。

原因：真实世界里自动扣费经常被活动价手动续费打断（B站扣一年实际到账 370 天），推算制会丢失服务区间被顺延的信息；而未记账的周期按标准价计入成本，保证懒人模式下成本不失真。代价是模型比 Wallos 复杂，且要求"付费记录"成为一等实体。

## Considered Options

- 纯推算制（Wallos）：简单，但无法表达"提前手动续费、金额与标准价不同"。
- 混合（默认推算 + 手动修正覆盖）：被采纳为周期模式的行为，但需要显式锚点改写语义，故以本文为准。
