# 联合会员的子会员即完整订阅

联合会员（如淘宝 88VIP）不是一条带分摊行项的整体记录：打包费是一笔付费，包内每个子会员都是一个完整的订阅实体，拥有自己的计费周期、到期日、付费记录和用量。其成本来源是从打包实付中按各子会员标准价比例分摊出的金额（原价未知时可手填分摊额），并以 source=BUNDLE 的付费记录物化到子会员上。

原因：同一联合会员内各子会员的周期和到期日常常不同（年卡 + 月卡混合），只有完整订阅才能复用到期提醒、日均成本、用量盈亏的全部既有逻辑；闲置子会员的成本照算并在盈亏中显示净亏，是退订决策的依据。代价：创建联合会员需要逐个录入子会员及其原价。

## Considered Options

- 整体记录 + 分摊行项：实现简单，但子会员无法拥有独立到期日与用量，盈亏分析无从谈起。
