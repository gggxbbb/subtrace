# 货币：录入时快照固化

每条付费/物品记录同时存储原币金额与录入当时折算的主币种金额，此后所有成本计算只读主币种快照，修改汇率不影响历史记录。用户级汇率表（每个币对可选自动 API 更新或手动钉住）仅在录入时预填折算值，用户可当场改。

原因：历史成本应按交易时汇率入账（会计惯例），"改汇率全局重算"会让昨天的账因今天的汇率波动而变化；快照语义也让成本引擎退化为纯单币种，大幅简化。代价：录入外币记录时多一个字段，且快照与最新汇率可能偏离（这正是预期行为）。

## Considered Options

- 记录只存原币 + 汇总时按当前汇率折算：账随汇率漂移，成本引擎必须全程带币种。
- 全系统单币种：外币订阅折算无据可查。
