# 进程内任务调度：croner 注册表 + JobRun 持久化

所有周期任务（系统任务：提醒扫描、汇率刷新；用户任务：用量脚本）统一注册到进程内的 croner 调度注册表，各自声明 cron 表达式，由库直接调度（替代早期的"每小时手动 tick + 内存态日期比对"——那套只支持日级节拍且重启语义靠手工维护）。

每次运行落一条 JobRun（jobKey、起止、耗时、成败、消息/日志），任务大盘页据此展示状态与下次运行时间；每 job 只留最近 50 条。重启后系统任务按"今天是否已有 JobRun"补跑一次（提醒/汇率漏跑有实际损失），用户脚本不补（额度快照幂等，下个触发点拉到的就是当前值）。并发安全靠 croner 的 protect 防重入与 ReminderDelivery 唯一键幂等。

选型 croner 而非 node-cron/CronJob：TS 原生、零依赖、白拿 nextRun（大盘页展示）与 protect 防重入。
