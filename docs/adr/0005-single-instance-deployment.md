# 单实例部署是项目约定

subtrace 面向家庭/个人自用，约定以 Docker 等形式**单实例**部署（多用户但单进程）。这条约定是后续一系列架构选择的前提：进程内 cron 调度（无需外部调度器即可每日跑提醒/汇率刷新/用量脚本）、node:vm 运行用户脚本（不考虑多租户隔离）、SQLite 单文件库（无并发写竞争）。

如果未来要水平扩多实例，调度与脚本执行必须抽出为独立 worker，cron 触发改为外部 cron 打 HTTP（`/api/cron/*` 路由保留为这条逃生门），沙箱也必须换成强隔离方案。多实例场景用 `REMINDER_SCHEDULER=off` 关闭内置调度。
