# 省钱型用量口径：已省金额即价值

折扣类会员（京东 Plus、88VIP、盒马 X）的价值不是"用了多少次"而是"省了多少钱"——平台直接给出"当期已省"。为此新增第三种用量口径**省钱型（SAVINGS）**：UsageRecord 的 quantity 即已省金额（主币种），只存增量（DELTA），区间内求和即价值；盈亏 = Σ已省 − 已摊成本，辅以回本差额，不显示每次实际成本。录入允许直接填增量，或填平台累计值由 UI 自动与上一条求差。

联合会员中的折扣权益（如 88VIP 的淘宝折扣）按 ADR-0002 惯例作为一个子会员订阅（省钱型），以手填分摊额获得成本基——否则打包费被其余子会员按比例摊满后，折扣权益成本为零，盈亏恒正、失去退订判据。

## Considered Options

- 复用计数型（单位"元"、替代单价 1）：数学等价，但概念在 UI 不可见、每次实际成本指标无意义、脚本准入需破例。
- 快照取最新（TOTAL-latest，同额度型）：平台"已省"随会员期重置，跨区间对不齐；混录时"快照优先"规则静默丢增量。
- 省钱型开放用量脚本：已省数据在登录墙后且有反爬，暂无可行抓取方案；本次仅手动录入，脚本仍限额度型，未来可行时再扩准入。
