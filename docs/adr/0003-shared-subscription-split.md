# 共享订阅：单一实体，查询时按权重分摊

多人共用的订阅（如家庭视频会员）只有一份实体，归付款人（所有者）所有并独占编辑权；成本不为每个受益人复制记录，而是在查询时按受益人权重切片。改分摊权重全局重算所有历史区间，不引入生效日期。受益人只读订阅全貌；用量与盈亏按受益人各自独立记录和计算（各自的成本份额 vs 各自的用量价值）。

原因：复制记录会产生多份需要同步的事实源；分摊规则本质是"这笔钱谁受益"的当前判断，个人记账场景里追溯重算比冻结历史更直觉。代价：查询层要做权重计算，且历史报表会随后续改比例而变化。

## Considered Options

- 每受益人一条订阅记录：数据重复，到期日/付费需多处维护。
- 分摊规则带生效日期：财务严谨但个人场景过度设计。
