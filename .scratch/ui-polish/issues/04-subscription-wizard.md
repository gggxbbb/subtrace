# 04 — 新建订阅四步向导

**What to build:** 将新建订阅的单页长表单替换为四步向导：①基本信息（名称/分类/起始日期）→ ②模式与周期（跟踪模式选择；周期模式展开周期形态与字段、标准价、币种、自动续费）→ ③首笔与提醒（周期模式显示首笔付费块；提醒天数）→ ④确认（摘要+提交）。手动模式下②无周期/价格字段、③无首笔付费块，步骤自然瘦身。分步模式与视觉复用启用用量跟踪向导（步骤指示器、上一步/下一步、逐步校验）。最终一次性提交现有创建动作，字段全集与创建能力零丢失。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 四步向导含步骤指示器、上一步/下一步导航、逐步校验（未过校验不能进下一步）
- [ ] 手动模式下周期/价格字段与首笔付费块不出现
- [ ] 创建能力与原单页表单完全一致：周期/手动模式、日历周期/固定天数、标准价与币种、自动续费、首笔付费（金额/来源/支付日期/服务起止）、提醒天数
- [ ] 服务端校验失败仍经 ?error=1 路径提示
- [ ] 确认步展示完整摘要，提交后创建成功并跳转
- [ ] 订阅编辑页不在本 ticket 范围
