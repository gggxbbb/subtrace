# 03 — 用量向导决策树（选型改为自然语言三问）

Type: task

**What to build:** `UsageWizard` 的「类型」步替换为决策树。① 首问「这个订阅怎么给你价值？」三选——按次使用（健身房 · 按摩 · 洗车）/ 每月给定量（流量机场 · iCloud · API 点数）/ 消费折扣（京东 Plus · 88VIP · 盒马 X）——映射 COUNT / QUOTA / SAVINGS 并预填默认值；类型术语降级为选项卡小字标注。② 额度型追问「额度怎么发？」——每期重置（到期没用完就清零）/ 逐期累积（多包共存、各自到期）——映射 RESET / STACKED，沿用现有形态说明与警告模式。③ 参数步按口径收敛只露必要字段，每项附一句「填什么、不填会怎样」+ 默认值（COUNT：单位、替代单价；QUOTA-RESET：总额度、用量周期；QUOTA-STACKED：每周期下发量、包有效期月数；SAVINGS：无字段说明文案沿用）。④ 「概念」步同步收敛为决策树的一句话引子（现有三段类型讲解删除或并入选项描述）。⑤ 编辑已有配置（`initialKind` 存在）跳过决策树直接进参数步；类型切换失真警告、形态切换警告行为不变。确认步不变。

**Blocked by:** 无

- [ ] 参数区每项「填什么、不填会怎样」+ 默认值
