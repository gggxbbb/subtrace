# reports-redo：报表页重做

## 背景

现报表页只有摊销单口径：4 KPI（摊销/实付/日均/分类数）、CSS 柱趋势、分类占比条、明细表。与全站脱节——用量盈亏、现金流对比、订阅/物品拆分都看不到。三轮 grilling 拍板重做（决策 1–17 全录于下）。

## 拍板决策

**用途（Q1/Q5）**：复盘 + 监控 + 对账三合一，单长页分层：盈亏复盘 → 现金流/趋势 → 分类 → 明细+导出。

**时间模型（Q2/Q13/Q16）**：顶部三档切换 月 | 年 | 自定义；自定义展开起/止日期输入 + 应用；月/年保留前后翻页。趋势粒度自动：区间 ≤62 天逐日，否则逐周/逐月（月视图逐日、年视图逐月即其特例）。

**用量盈亏（Q3/Q6/Q14/Q15）**：进报表且为头号板块。按所选区间计算，定性「回看」（ADR-0015，headline 场景维持 ADR-0014 滑动窗）。行 = 名称 + 口径标 + 付了 + 用回 + 净盈亏 + 每次实际成本 + 到期/重置倒计时 chip；净盈亏沿用红/绿/灰四态（pnlTone），含 valueUnknown/valuePartial/costUnknown 标注。KPI 行 R4「分类数」替换为「区间盈亏」汇总。包含范围：区间内有摊销成本或有用量记录的量化订阅。

**现金流（Q7/Q8）**：趋势图升级双口径——摊销 + 实付两条系列同框，看出「年付大月」与日常摊销的差。零依赖手绘 SVG：折线/面积 + 格栅线 + 悬浮读数（title），延续 LED/工业语言，不引入图表库。

**订阅/物品拆分（新增需求/Q11/Q12）**：不是开关，常驻可见。
- 首页：A1「当日总日均」副标题改 `订阅 ¥X · 物品 ¥Y`；「≈每月」挪进悬浮 title；A3 副标题撤掉物品日均（重复），改纯订阅信息。
- 报表：R1「摊销成本」与 R3「日均」副标题各加 `订阅 X · 物品 Y` 拆分。

**导出（Q9/Q17）**：两个 CSV 各一链接——「明细.csv」（名称/类型/分类/摊销/日均/占比）、「实付流水.csv」（日期/名称/原币金额/折算主币金额）。UTF-8 带 BOM（Excel 中文兼容）。

**不做（Q10）**：物品回本进度不在报表单设板块（控制台已有；明细表已含物品行）。

## 页面结构（单长页，自上而下）

1. Header：三档切换 + 翻页/区间标签（+ 自定义起止输入）
2. KPI 行：R1 摊销成本（环比 + 订阅/物品拆分副标题）、R2 实付、R3 日均（拆分副标题）、R4 区间盈亏
3. 01 · 用量盈亏（回看口径，头号板块）
4. 02 · 趋势（双口径 SVG：摊销 vs 实付）
5. 03 · 分类占比（保留现状样式）
6. 04 · 明细表（保留 + 订阅/物品标） + 导出链接 ×2

## 验收口径

- 报表任意区间下，用量板块数字与同一区间手工核算一致；缺价/成本未知三态标注齐全
- 趋势图双系列、粒度随区间长度自动切换、悬浮读数可用
- 首页 A1 可见订阅日均与物品日均，A3 不再有物品日均
- 两个 CSV 下载内容与页面口径一致，Excel 打开中文不乱码
- 移动端同权（单栏堆叠，无横向滚动条外露）
