# 12 — 金额未知的付费记录

**What to build:** 大量存量订阅用户只知道到期日、不知道实付金额。付费记录的金额（原币与主币种快照）允许为空：到期日/服务区间照常生效（记录驱动语义不变），成本段净额未知时不产生费率、当日总日均不将其计入，UI 在订阅详情与列表标注"金额未知"。后续知道金额时可补录。

**Blocked by:** 03 订阅核心链路

**Status:** resolved

## Answer

Payment.amount/currency/amountBase 可空（null=未知，区别于 0）；引擎 CostSegment.amountUnknown、净额置 0 费率为 0 不计入合计，currentExpiry 只看区间故到期日语义零改动；记付费金额可留空（区间必填），币种随金额同为 null；汇总点（详情 B3/dashboard 实付/reports totalPaid）null 过滤。UI：付费记录行「金额未知」徽标、详情 B2「未知·成本不计」、列表日均「未知」、用量盈亏在未知段显示「成本未记录，盈亏不可信」（不计血赚）。补录=编辑记录填回金额。ADR-0004 已补例外条款。

- [x] 记付费时金额可留空（区间必填）
- [x] 金额未知的记录照常决定到期日
- [x] 金额未知的成本段费率为 0 且不计入任何合计
- [x] UI 标注"金额未知"，可后续补录金额
- [x] 手动模式订阅可以只记录到期日（零金额记录）
