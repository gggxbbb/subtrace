# 06 — 用量与盈亏（手动录入）

**What to build:** 可量化订阅的用量手动录入与盈亏。两类用量口径：**计数型**（逐条录入日期+数量，如健身房次数）；**额度型**（录入当前使用百分比，或总额度+已用额度，如 coding plan 点数）。替代单价设置、订阅详情页按服务区间展示盈亏（用量×替代单价−已摊成本）与每次实际成本、dashboard 红黑榜（盈亏排序）。

**Blocked by:** 03 订阅核心链路

**Status:** ready-for-agent

- [ ] 可为订阅设置用量类型（计数/额度）、单位与替代单价
- [ ] 计数型：逐条录入/删除用量记录
- [ ] 额度型：录入使用百分比（自动折算已用量）或总额度+已用额度
- [ ] 详情页按服务区间显示盈亏与每次实际成本（当前区间实时、历史区间可回看）
- [ ] Dashboard 红黑榜按盈亏排序，亏损标红
