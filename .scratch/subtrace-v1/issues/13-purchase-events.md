# 13 — 物品追加费用事件

**What to build:** 物品买入后的生命周期费用事件：加保（AppleCare）、配件、维修等。每个事件记录日期、金额（主币种快照）、类型（加保/配件/维修/其他）、备注。摊销口径（默认，可调）：**计入物品净额、共用同一摊销窗口**——手机 8000 + care 1000 → 净额 9000 仍按 购买日+预期寿命（或摊至今日）计算费率；维修后可同时上调预期寿命。物品详情页显示事件时间线与累计净额。

**Blocked by:** 04 物品与回本模型

**Status:** ready-for-agent

- [ ] 可为持有中物品追加费用事件（日期、金额、类型、备注）
- [ ] 事件金额计入物品净额，费率按统一窗口重算
- [ ] 维修事件可选同步延长预期寿命
- [ ] 详情页展示事件时间线（买入 → 加保 → 维修 → …）与累计净额
- [ ] 事件可编辑/删除，净额联动重算
- [ ] 卖出/报废时残值仍从累计净额中扣除
