# 13 — 物品生命周期费用：追加事件 + 关联订阅

**What to build:** 物品买入后的两类后续费用，分开建模、统一呈现：

1. **一次性追加费用事件**（配件、维修等）：日期、金额（主币种快照）、类型、备注。计入物品净额、共用同一回本摊销窗口（手机 8000 + 维修 500 → 按 8500 摊）；维修可选同步延长预期寿命。
2. **关联订阅**（AppleCare、iCloud 等周期性费用）：就是普通订阅，通过 `Subscription.purchaseId` 关联到物品。成本走订阅自己的成本段，不进物品净额。

物品详情页：TCO 视图 = 物品摊销 + 关联订阅在持有期间的摊销，并列展示追加事件时间线与关联订阅列表；订阅详情页显示关联的物品。

**Blocked by:** 04 物品与回本模型

**Status:** ready-for-agent

- [ ] 可为物品追加一次性费用事件（日期、金额、类型、备注），计入净额统一摊销
- [ ] 事件可编辑/删除，净额联动重算；维修可选延长预期寿命
- [ ] 创建/编辑订阅时可关联到物品（可选，单选）
- [ ] 物品详情页 TCO = 物品摊销 + 关联订阅持有期摊销，分开展示两块
- [ ] 详情页展示事件时间线（买入 → 维修 → …）与关联订阅（含其到期日/费率）
- [ ] 卖出/报废时残值从累计净额（含事件）扣除；关联订阅不受影响
