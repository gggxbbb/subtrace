# 04 — 物品与回本模型

**What to build:** 物品 CRUD（名称、分类、金额、购买日期、可选预期寿命）、卖出/报废登记（日期、残值）、物品列表页与 dashboard 回本进度条。总日均并入物品摊销（回本模型：寿命内固定费率、超期摊至今日、卖出/报废摊至截止日扣残值）。

**Blocked by:** 03 订阅核心链路

**Status:** ready-for-agent

- [ ] 可创建有/无预期寿命的物品
- [ ] 持有中物品按回本模型显示当前日均与回本进度
- [ ] 卖出/报废后摊销终止并扣除残值
- [ ] Dashboard 当日总日均 = 订阅分摊 + 物品摊销
