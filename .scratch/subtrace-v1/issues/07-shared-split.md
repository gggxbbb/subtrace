# 07 — 共享订阅分摊（受益实体：用户 + 物品）

**What to build:** 订阅可添加受益实体并设置权重（默认均分，改权重全局重算）。受益实体两种：**用户**（家庭共享）与**物品**（iCloud 之于多台 Mac/iPhone）。所有者独占编辑权、受益用户只读查看全貌；dashboard 与订阅详情按权重切片展示"我的份额"；用量与盈亏按受益用户各自独立计算；物品 TCO 包含其作为受益实体的订阅份额（ADR-0003）。

**Blocked by:** 03 订阅核心链路, 06 用量与盈亏

**Status:** resolved

## Answer

Beneficiary 模型（USER 用户 / ITEM 物品 + 权重，ADR-0003）：首个受益人加入时自动补所有者占位行（进入分摊状态），占位行可移除（iCloud 纯设备分摊，所有者份额为 0），移除到只剩所有者时自动清除；份额 = 权重/Σ权重，改权重查询时即时全局重算。所有者独占编辑（付费/受益实体/状态），受益用户只读全貌 + 「我的份额」KPI + 按人独立用量盈亏（录入权限放宽到 USER 受益人，删除仅限本人记录）；所有者视角有各受益人对比（谁在用、谁纯亏）。dashboard 行按份额切片并标「共享·X / 分摊 N%」，实付统计只计自有订阅。物品详情页 TCO = 物品净额 + 持有期内订阅份额（段按重叠天数折算）。联合会员候选限自有订阅（共享不可转包）。

- [x] 可为订阅添加/移除受益实体（用户或物品）并设置权重
- [x] 仅所有者可编辑订阅、记付费、改受益实体
- [x] 受益用户只读看到订阅全貌与自己的成本份额
- [x] 各受益用户用量独立录入，盈亏按人计算
- [x] 物品详情页 TCO = 物品摊销 + 作为受益实体的订阅份额（持有期内）
- [x] 改权重后历史区间按新比例重算
