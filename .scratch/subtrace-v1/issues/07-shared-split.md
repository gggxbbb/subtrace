# 07 — 共享订阅分摊（受益实体：用户 + 物品）

**What to build:** 订阅可添加受益实体并设置权重（默认均分，改权重全局重算）。受益实体两种：**用户**（家庭共享）与**物品**（iCloud 之于多台 Mac/iPhone）。所有者独占编辑权、受益用户只读查看全貌；dashboard 与订阅详情按权重切片展示"我的份额"；用量与盈亏按受益用户各自独立计算；物品 TCO 包含其作为受益实体的订阅份额（ADR-0003）。

**Blocked by:** 03 订阅核心链路, 06 用量与盈亏

**Status:** ready-for-agent

- [ ] 可为订阅添加/移除受益实体（用户或物品）并设置权重
- [ ] 仅所有者可编辑订阅、记付费、改受益实体
- [ ] 受益用户只读看到订阅全貌与自己的成本份额
- [ ] 各受益用户用量独立录入，盈亏按人计算
- [ ] 物品详情页 TCO = 物品摊销 + 作为受益实体的订阅份额（持有期内）
- [ ] 改权重后历史区间按新比例重算
