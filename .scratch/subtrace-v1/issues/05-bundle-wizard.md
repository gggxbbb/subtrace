# 05 — 联合会员向导

**What to build:** 联合会员创建向导：录入打包价与起止日期 → 逐个添加子会员（名称、原价、各自周期）→ 按原价比例分摊预览（可手改某子会员分摊额）→ 确认为每个子会员创建完整订阅并物化 source=BUNDLE 的付费记录（ADR-0002）。

**Blocked by:** 03 订阅核心链路

**Status:** ready-for-agent

- [ ] 分摊金额 = 打包实付 × 子会员原价 / Σ原价，可手动覆盖
- [ ] 子会员成为完整订阅（独立到期日、可记付费、可算用量）
- [ ] 闲置子会员成本照常计入，盈亏显示净亏
- [ ] 原价未知子会员可按 0 元参与或手填分摊额
