# 05 — 联合会员向导

**What to build:** 联合会员创建向导：录入打包价与起止日期 → 逐个添加子会员（**关联已有订阅**或新建，填原价）→ 按原价比例分摊预览（可手改某子会员分摊额）→ 确认为每个子会员物化 source=BUNDLE 的付费记录（ADR-0002）。归属关系挂在付费记录上（Payment.bundleId，一个订阅可多次参与联合会员），子会员就是完整订阅。

**Blocked by:** 03 订阅核心链路

**Status:** ready-for-agent

- [ ] 分摊金额 = 打包实付 × 子会员原价 / Σ原价，可手动覆盖
- [ ] 子会员可关联已有订阅（向其追加 BUNDLE 付费记录，历史连续）或创建新订阅
- [ ] 关联已有订阅时服务起预填其当前到期日（顺延心智），可改
- [ ] 子会员作为完整订阅：独立到期日、可记付费、可算用量
- [ ] 闲置子会员成本照常计入，盈亏显示净亏
- [ ] 原价未知子会员可按 0 元参与或手填分摊额
